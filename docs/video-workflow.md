# 视频制作主线

完整方法与制作模板维护在[Video Production Workflows](../skills/video-production-workflows/SKILL.md)。真人电影感、动画、广告、MV、科普和现有素材剪辑采用相同的制作闭环，再按镜头需求选执行路线。

| 阶段 | 推进内容 | 产物与调用 |
|---|---|---|
| 制作简报 | 剧本/核心信息、审美参考、观众、时长、比例/分辨率、语言、声音、交付方式 | brief、要求与不能改变项；总流程统筹 |
| 风格与视觉开发 | 将参考拆成造型、光色、材质、构图、动作与节奏；按需角色/场景/道具和关键帧 | Qwen及图像编辑；style-and-continuity；Flova只在有参考价值时读公开方法 |
| 分镜与动态预演 | 镜头覆盖、叙事信息、时间、对白/音乐和接点；复杂片先全片animatic | shot-plan、临时声音、分镜图；精确相机/动作可Blender白模 |
| 难点试片与选路 | 身份近景、风格、复杂动作、镜头接点；选生成、实拍/已有素材、CG或合成 | Comfy模型执行、Blender或其他已确认工具；实际代表输入检验 |
| 镜头生产 | 绑定参考、提示词、采样/版本/缓存；串行生成，选片并对受影响项返工 | H3普通/Turbo/Flex及ControlNet等按需；H3提示词/类型Skill提供创作方法 |
| 粗剪、合成与声音 | 故事/节奏、镜头衔接、跟踪/遮罩、CG合成、配音/表演、音乐/拟音 | CapCut或用户已选本地后期；Ming/Music按需；准确文字/UI在后期制作 |
| 精修与统一 | 对选片局部修复/放大、光色统一、字幕/包装、声音平衡 | 模型/合成/编辑工具各司其职，不对全片无条件重绘 |
| 导出与验收 | 实际全片观看、接点、运动/小结构、口型/声音、规格与首尾 | 成片文件、可编辑项目、素材/版本索引、已知限制；media_qc是技术检查而非审美评审 |
| 交付与空间 | 明确交付物、可继续返工依赖和清理记录 | 项目内集中管理；每批/阶段及至少2小时检查 |

## 图像、分镜、白模的不同职责

Qwen可承担概念、造型、构图关键帧、首尾帧准备、静帧修复与合成素材，贯穿前期和返工。Next-Scene帮助探索下一镜的静态候选；它不是前一镜的真实末帧，也不自动保证地理和人物完全一致。

Blender RGB预演可传达外观/运动意图；需要逐帧结构依据时，导出同步深度、骨架/姿态、边缘与必要蒙版，按当前H3 Fun支持的输入接入。尺寸、时窗、FPS、帧数、深度范围和坐标必须统一。物理接触和精确相机硬要求仍可选Blender实际渲染/合成；生成模型不直接执行`.blend`的几何或碰撞。

## 连续视频与LoRA

先区分可剪独立镜头与同一时空延续；段间继承、相同底模/家族、参考/时间线/缓存名由Comfy执行Skill核对。动作/风格LoRA是可选的生成倾向；导演台分组切换不自动保证跨段连续性。普通、Turbo、Flex的噪声表、条件和采样配套不混用。按代表镜头判断效果，不把评分或一次成功变成全场景保证。

## 配音配乐与后期

配音先短句校准再长文；参考转写、时长、角色与表演明确。Music是配乐/演唱模型，不当精准拟音或无限无缝音乐器。最终在实际时间线对齐对白、环境、拟音、配乐与字幕。云草稿、本地桌面工程、已导出成片分别记录；素材已上传或草稿保存不等于交付完成。
