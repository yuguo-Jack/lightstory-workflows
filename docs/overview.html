Game Production

简报与创作方向 → Web / Unreal选路 → 可玩灰盒 → 品质切片 → 资产与功能生产 → 集成与性能 → 打包试玩。

玩法、美术和UI模块按需调用；Comfy与Blender负责资产，Web调用Game Studio，Unreal走引擎工具，过场与视频接入Video流程。

Video Production

剧本与规格 → 视觉开发 → 分镜 / animatic → 难点样片 → 镜头制作 → 合成剪辑与声音 → 成片播放验收。

生图负责身份、风格与关键帧；H3按镜头选路；Blender预演和结构引导用于控制；配音配乐与后期独立检查。

从哪一步开始

  1. 配置机器路径，运行validate和doctor。
  2. 按需安装Skill、节点、模型与客户端插件；第三方版本和许可各自管理。
  3. 新建制作项目或恢复已有状态，用户给玩法、剧本、风格和交付要求，执行者按总流程推进。
  4. 单项生成直接用Comfy Skill；只有项目需要特化时才另存Projects栏目。
历史模型记录与源码安装检查分别列明；新环境的GPU品质、实际游戏和成片仍按自己的素材验收。模型、用户素材和账户信息不随源码分发。
Comfy执行Blender与动作插件和外部工具模型与许可更新与清理从原机迁移验证边界
