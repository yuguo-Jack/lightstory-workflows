做什么，按需组合。

独立游戏、第一 / 第三人称和俯视游戏、叙事短片、广告、三维资产、配音配乐与批量内容生产。游戏总入口选择Web或Unreal路线，视频总入口编排从剧本到成片的工作。

Qwen-Image-2.1准备概念与关键帧，Pixal3D生成模型和材质，SkinTokens辅助绑定；Blender精修与预演，MiniMax H3生成镜头，Ming-3.0-TTS Tiny和MiniMax Music 3处理声音。

开始使用的顺序。

  1. 安装并配置：按文档配置已有软件与所需分支，检查路径和依赖。
  2. 选择入口：游戏用Game流程，成片用Video流程，单项生成直接用ComfyUI流程。
  3. 提供创作要求：目标、剧本 / 玩法、参考风格、时长与规格；分阶段制作、检查并返工。
