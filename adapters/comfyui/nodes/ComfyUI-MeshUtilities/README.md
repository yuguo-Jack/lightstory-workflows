# Mesh Utilities

通用节点 `Unwrap Mesh UVs (Preserve Normals)` 使用 ComfyUI 原生 UV 展开算法，通过 UV 生成器返回的顶点映射精确保留输入法线。适用于任意输入网格，不含人物、配色、眼窝定位等特化逻辑。

放在网格重建、减面、平滑法线之后，纹理烘焙之前。无需额外 Python 依赖。

针对 ComfyUI v0.43.0 核对。原生 `UnwrapMesh` 在该版本未向输出传递已有法线；本节点通过独立扩展处理，不修改 ComfyUI 核心文件，避免升级时覆盖修复。它依赖原生 UV 辅助函数，后续核心升级若改变接口应再做兼容检查。

UV 展开会复制缝处顶点，不改变基础几何，也不修正生成模型的解剖、孔洞或多视图不一致。生成后仍需检查 UV 缝法线连续性。

实现基于 ComfyUI 的 GPL-3.0 代码，沿用 GPL-3.0。
