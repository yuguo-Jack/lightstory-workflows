# 来源与本机适配

2026-11-01由 [sickn33/agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills/tree/1ed5976b000fc0df2910d32ed33717794da1bee2/skills/game-development/game-design) 的 `game-design` 模块安装并适配，本机名称为 `game-design-theory`；保留 [MIT许可证](../LICENSE)。原仓星数属于整个技能集合，不是本模块的独立质量评价。

本机修改：精简入口；增加设计假设与反例、体验/美术区分、按问题选框架、真实试玩与状态依赖；去除通用固定时长/成功率与无关执行约束；接回现有Web/UE、UI和美术流程。不是同名 `pluginagentmarketplace/game-design-theory` 的直接安装；该候选已比较，其自定义许可和外部Agent绑定未引入。

MDA核对自 [Hunicke、LeBlanc、Zubek原始论文](https://www.cs.northwestern.edu/~hunicke/pubs/MDA.pdf)。理论用于提出和检验设计假设，不保证成品质量。本轮验证技能结构与路由，没有制作新游戏或做玩家效果实验。
