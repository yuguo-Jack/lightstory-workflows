# 视频制作简报

这是项目模板，按实际需要填写/删减；不是询问用户逐项确认的表单。

- 项目与工作目录：
- 用户已提供的剧本/素材/审美参考：
- 已有合格素材及可直接复用部分（无需重新生成）：
- 用途、观众、平台及应传达的内容：
- 类型与主要情绪变化：
- 核心剧情/事实/品牌/人物不可改项：
- 允许发挥部分及明确排除项：
- 成片时长范围、比例、交付尺寸与 FPS：
- 生成/精修尺寸策略（与交付尺寸区分）：
- 语言、对白/旁白、字幕、准确画面文字：
- 主声音来源：用户音乐 / 本地配音 / H3 原声 / 新配乐 / 无声：
- 主风格、人物/场景/服装锚点（链接风格连续性记录）：
- 可观察质量要求与优先级：身份/外观、关键动作、风格属性、文字/对白、时间/规格：
- 生图计划：角色/道具/场景定稿、色光样张、逐镜关键帧及版本：
- 动态分镜：临时声音/主音乐、预览文件、实际时长与当前问题：
- 是否需要动作/运镜预演及准确性要求：
- 各类镜头采用的文生/图生/视频编辑/CG/合成路线，以及主要控制难点：
- 已验证代表镜头、实际耗时/资源与可接受精修范围：
- 工期/资源约束、各镜头质量优先级及先验证的高风险项：
- 交给模型/Blender/剪辑执行技能的任务与返回记录位置（共用本项目，不另建嵌套项目）：
- 编辑目标：已有项目 / 本地 CapCut / CapCut 云端 / 确定性合成：
- 用户对上传/收费/发布的实际授权范围（没有的不要推断）：
- 交付：成片 / 可编辑工程 / 引用媒体 / 字幕 / 音轨 / 封面（按请求）：
- 时长要求是精确值还是范围；分辨率指原生生成、后期精修还是最终导出：
- 关键难点与首批验证镜头：
- 当前通过版本、待修复项和下一步：
- 需要继续保留的缓存及原因：
- 制作期空间管理：默认每批生成、渲染、构建及阶段结束后检查清理，连续工作每2小时检查；临时数据较上次检查增长30 GiB、累计超过60 GiB或可用空间低于60 GiB提前盘点；必要增长可保留，本轮可无需清理，实际容量足够时继续工作；项目调整值与理由：
- 本项目及实际工具原生临时目录/缓存组、磁盘基线、下一批预计额外峰值和余量：
- 最近空间检查/清理记录、下次检查时间、保留缓存的消费者/结束条件：

素材清单记录原件路径、职责、使用范围及是否作为准确内容依据。重要选择从本简报读取，不靠一条旧聊天摘要重置。
