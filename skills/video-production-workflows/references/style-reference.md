## 本机采用的风格提炼法

先看用户样例，再选择有用的风格参考。输出一份可核对的 style-and-continuity，而非只写导演/工作室名：

1. **形状与造型**：头身、轮廓、细节密度、材质粗糙度及哪些外观必须保留。
2. **构图与摄影**：景别、相机高度、透视、留白、对称/偏心、焦点和运动速度。
3. **光色**：主光方向与软硬、填光、反差、白平衡、主辅色和黑位；不靠统一滤镜覆盖不同时间/天气。
4. **运动与时间**：动作准备/峰值/收势、镜头运动幅度、停顿、切点和声音入点。
5. **叙事与声音**：信息如何推进，音效/环境先后、配乐功能和是否用对白。
6. **反例与容差**：用户不想要的塑料感、过曝、阴影过长、晃动、镜头炫技等，仅按本片要求记录。

一个项目选一套主视觉系统，其他参考只借明确层面，例如某参考的镜头节奏与另一参考的材质，不让它们同时改角色和场景。做代表镜头对照，让用户样例或明确偏好决定方向，不用工具输出替代用户审美。

## 落到执行工具

外观/风格锚点交给 Qwen 参考编辑；动作/镜头按需 Blender 预演；H3 用模式对应的参考与时间描述；节奏/文字/声音/最终光色由 CapCut 或合成流程完成。Flova 的 Resource/Asset/Sequence/Composition 概念分别映射到本地素材版本、分镜计划、实际选片和编辑时间线，不复制其私有项目结构。

风格图里的字体、水印、直播 UI 或无关人物不作为正式画面内容；必要时先准备干净参考，保留原图。风格好看不等于身份、物理和文字准确，仍按镜头目标验收。
