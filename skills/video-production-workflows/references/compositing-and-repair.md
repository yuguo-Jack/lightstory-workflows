# 合成、动态修复与包装



它们是镜头制作中的独立工序，不能假设生成视频后只要剪接就足够。简单切片、时间线叠层、标题和声音用 CapCut；需要动态遮挡、透视跟随、干净底板或CG融合时按任务使用 Blender 的跟踪、遮罩和合成。实际节点/API先查当前 Blender 技能/本地接口；这些能力尚未在本技能中以所有场景逐一验收。



## 先诊断，再选修复层级



| 问题范围 | 优先路线 |

|---|---|

| 单张起始图/末帧就有错 | Qwen局部修复后再生该镜头，避免把错误传入运动 |

| 只需改时长、镜头顺序、音轨、字幕、标题 | 编辑时间线；无需重新生成整个镜头 |

| 场景中的招牌、屏幕、Logo或道具贴花必须准确 | 正确静态素材 + 位置/平面或相机跟踪 + 遮挡遮罩；检查透视、运动模糊和反射 |

| 局部几帧或一小段动作坏了 | 保留上下文返工短段/重做本镜，检查两侧时序接点；不要逐帧独立画图 |

| 需要除物、换背景、增加可控前景/CG效果 | 干净底板/参考、动态遮罩/跟踪、分层合成；评估视差与遮挡，不仅是静态羽化贴图 |

| 握持、碰撞、人数、产品几何或相机必须精确 | 确定性Blender动画/渲染，或准确CG部分与其他素材合成 |

| 全片闪烁/身份漂移/形体失稳 | 回到参考和生成路线；若需专用时序修复模型则单独调研验证，不能用锐化或一张修图遮住全片问题 |



视频编辑06/07是生成式修改，不能默认只改目标区域。需要结构引导的局部变更时，可选`MiniMax H3/结构控制/04_结构引导视频局部重绘`：本镜原片、同步控制片及随运动的白改黑保蒙版，另有最终合成保护；用法与实测范围读ComfyUI执行Skill的`references/h3-controlnet.md`。编码前黑区保护与有损MP4像素一致是不同要求，动态边缘、投影/反射及接点仍须审查。静帧蒙版不能自动成为视频跟踪遮罩，也不把本机单镜样例当成任意镜头一键精准修复。



## 动态合成最小合同



1. 定义源镜头、帧范围/FPS、修复目标和必须保留内容；保留源片与未合成版本。

2. 根据运动选择二维点跟踪、平面/透视关系、相机求解或手工关键帧。自动跟踪有遮挡/模糊/漂移就人工修正，不能只看首尾位置。

3. 制作需要的底板、前景、图形、CG和动态遮罩。静帧RGBA只能提供静态抠图，不能代替视频时序分割；大遮挡后重新出现需另检查。

4. 对齐物体尺寸、透视、深度顺序、光色、接触影、反射、运动模糊和颗粒。检查Alpha预乘/边缘、光晕及影子是否被截断；不是把原图小目标带一圈背景贴回去。

5. 沿整个修复范围播放并抽查困难帧。边缘、遮挡和投影必须跟随运动，不能只保存一张漂亮结果；合成后重新检查剪辑与声音时点。



本机Qwen可辅助底板、元素与参考图制作；Blender可承担手工/关键帧遮罩、跟踪、3D渲染和合成，CapCut负责整体编辑和相对简单叠层。每项具体交互与脚本要按项目实现及验证，不把上述方法论当现成一键修复节点。



## CG、视频和音效的混合



按难点分工：精确结构/运动用CG，气氛/环境/B-roll可用H3；必要时直接交付高质量CG镜头，不强制每镜再过生成模型。CG渲染设置与生成素材的色彩基线匹配，避免重复显示变换。接触、光线和遮挡关系是融合关键，模型名和滤镜不能代替检查。



需要火焰、烟雾、雨、粒子、布料等时，按镜头选择H3生成、Blender模拟/程序效果或合法素材；不是每种效果都默认模拟。确定性模拟需烘焙与保存必要缓存，最终无返工需求才按收尾规则清理。



## 准确文字与动态图形



标题、字幕、歌词、信息图、UI演示、Logo与片尾按需单独规划字体、布局、动效与安全区。用真实文字/图形资源在后期排版，重要界面可用真实屏幕录制或受控动画；不用模型重画品牌或数字。



独立包装轨道保持可编辑，跟踪中的文字仍遵守遮挡/透视；多比例交付要重新审查排版和裁切。若某 CapCut 模板/效果不可用、收费或当前工具不支持，选择已授权的普通排版/动画或Blender实现，不以同名功能存在就宣布完成。



稳定、去闪烁、补帧、降噪、超分、运动模糊只在缺陷和交付目标需要时用。它们不是每片必经的增强串联，也不能修复错误动作；明确区分当前可用操作和需要额外模型/插件的候选能力。
