# 生图模型贯穿视频制作的职责

本机首选已部署的 Qwen-Image 2.1 INT8。将图片目标、输入职责、保留项和本项目请求位置交给 `$comfyui-local-workflows`；由其按当前目录及Qwen参考选择、准备和执行。这里规定美术素材的用途、选择与交接，不维护第二套API或假设已部署其他模型。

## 不同图片承担不同任务

| 图片任务 | 产物及用途 | 本机路线 |
|---|---|---|
| 概念美术/视觉探索 | 少量造型、材质、光色、构图方向；选定本片视觉依据 | 01 文生图，02 单图编辑；保留有代表性的选择，避免无边界海选 |
| 角色/服装/道具定稿 | 面部、全身、必要侧背、服饰细节和重复道具；供跨镜头稳定引用 | 01/02/03；多要素才考虑07五参考，不因槽位多就全部填满 |
| 场景与空间依据 | 场景全景、关键机位、主要陈设、出入口/遮挡关系 | 01/02/03；复杂空间用 Blender 布景和相机校准，再决定是否由图片润色 |
| 色彩/光线脚本 | 关键场景的色光样张与情绪变化；保持全片有依据的变化 | 01/02；不强制每镜同一色温、时间或天气 |
| 构图分镜与关键帧 | 同一角色在本镜机位、动作起点/终点下的完整画面 | 02/03，必要时07；与场景、角色定稿绑定，进入H3 03/04/05/18 |
| 下一镜候选/链式故事板 | 围绕当前图改变景别、机位或揭示环境，供镜头覆盖和animatic选片 | `分镜/01_下一镜头生成`或`02_链式分镜生成`；逐镜选定，不把未知背面当真实几何，不默认无缝 |
| 布局/空间受控美术 | 沿用源图/白模轮廓或深度，改变材质、外观和画风 | `结构控制/01–03`；边缘/深度提供结构，身份参考另供，局部保护核对同一坐标 |
| 关键帧局部修复 | 修手、物件、服装、文字占位、背景干扰等，尽量保留合格部分 | 04蒙版局部编辑；核对处理后的坐标、扩张/羽化和边界，不能只写prompt保证不动其他部分 |
| 分层/透明元素 | 干净前景、插图、可控道具、贴片或包装素材 | 05透明背景文生图/06抠图；检查真实Alpha，半透明、毛发与镂空 |
| 后期修补素材 | 清理背景底板、局部替换元素或重绘参考，用于后续跟踪/合成 | 02/04/06；静帧素材要通过时序流程进入视频，见[合成与修复](compositing-and-repair.md) |
| 封面/片头/片尾美术 | 需要的封面、海报、标题背景、片尾画面 | 01/02；准确文字/Logo尽量保留真实素材或后期排版，不每片都强制制作海报 |

## 分开定稿与镜头光照

身份/商品依据尽量清楚、少遮挡、光线可辨，不把强色光、景深或烟雾当作身份特征。镜头关键帧再加入本场灯光、环境和情绪。角色多视角、表情和服装细节按实际用到的镜头准备，不必每个人都生成完整设定集。

独立生成的侧面/背面可能改脸、头身、扣件、发型或颜色；逐项比较后才加入参考库。不能通过“图片更多”弥补互相矛盾；必要时只保留最稳的少数锚点。多视图参考图也不是几何严格一致的三维物体。

图片定稿后在 `shot-plan.json` 的 visual_assets/visual_inputs 中记录ID、版本、路径、职责和审查状态；替换角色/场景定稿要标出受影响镜头，不让早期未选版本混入正式生成。

## 从静帧到视频的交接

需要Next-Scene时，复用已认可首镜，描述下一镜机位/景别、动作和保留项；触发格式、回接预处理和真实配置由ComfyUI执行技能的`references/qwen-extensions.md`维护。生成的PNG逐镜检查后写回镜头表；新种子/素材仍可能复制、颗粒或身份/地理漂移，出错回到干净锚点开分支，不将错误逐镜传下去。它是选做的静帧分镜辅助，不替代外观定稿、动作预演和剪辑。

1. 按计划机位与景别生成本镜起始画面。检查主体数量、身份、手持关系、地面接触、出入画空间、运动方向，以及后期文字/裁切安全区。
2. 需要终点时，以同一身份/场景依据编辑末帧，检查是否能在所给时间内连续到达；首尾帧并不保证中间路径准确。
3. 需要中间姿态或路线时，将其作为分镜/预演依据；只有当前节点实际支持的槽位才能接入模型。不能凭计划中的“中间帧”字段臆造任意时间点硬约束。
4. 图生视频的首帧使用干净单幅完整画面。九宫格、带文字分镜、不同角色拼贴先选出/裁出单镜并清理边框；角色设定表作为参考时也要明确职责，检查是否出现多人复制或面板泄漏。
5. 原件保留。预处理副本统一所需比例/方向/色彩/尺寸，记录缩放、裁切及蒙版变换；大图不自动等于更好，按视频输入和本机内存准备。不能拉伸人物凑尺寸。
6. 用正式H3模式接入图片并说明动作、相机和声音。参考图职责不混用：身份图定义“是谁”，关键帧定义本镜初始/结束画面，风格图定义视觉属性，预演视频定义运动意图。

需要从横屏改竖屏时，先评估重构图、扩画幅或重新生成关键帧，再检查后续视频；本机目录没有独立验证的专用扩图画布，若用图像编辑/合成试做必须标为该项目验证，不能凭文档说已经支持一键无缝扩图。

## 静态画面也可以是正确路线

信息图、图文解说、品牌排版、低运动插画、照片叙事可用分层图片、编辑器关键帧或 Blender 平面/2.5D 相机制作，再和生成镜头组合。适度移动/缩放不等于真正三维绕拍；露出原图没有的侧面需要补素材/几何。用户要求人物动作或真实物理时，不能用静图推拉代替。

图片阶段先处理明显错误通常比让H3带着坏起始图运动后再修省事；但不能把每一视频帧分别Qwen重画当成稳定视频增强器。
