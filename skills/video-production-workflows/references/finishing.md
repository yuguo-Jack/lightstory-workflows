# 后期与成片验收

## 技术目标与真实性

交付先按用户/渠道规格；未指定可建议 H.264 MP4、SDR Rec.709、yuv420p、CFR、AAC，横屏1920×1080或对应竖屏作为兼容起点。这是交付约定，不是本机 H3 原生生成质量或所有平台的强制要求。高质量母版/透明通道/专用封装按项目另定，确认编辑器真正支持。

生成图常是显示参照 SDR，Blender 的线性渲染/显示变换与编辑器素材也可能不同。记录输入和输出色彩，不给所有片段盲套 LUT、重复应用 AgX 或把现成 SDR 当 Log。检查黑位、白位、肤色、饱和与裁切；通过两处播放器对照异常，不能只补写色彩标签掩盖实际错色。

先消除镜间曝光/白平衡差异，再做有依据的全片风格。降噪、锐化、颗粒、运动模糊、补帧、放大都按素材使用；过度锐化/补帧会破坏脸、手和接触。现有潜空间放大/二采不是已部署专用 VSR；需要真视频超分时另行选择并验证，不凭 UI 选项声称可用。

## 三层验收

**结构/技术**：视频可解码，真实尺寸/FPS/帧数/时长正确；音轨存在且有效，字幕/颜色/编码符合目标，文件路径可用。可运行：

```powershell
python -B -X utf8 '${SKILLS_ROOT}\video-production-workflows\scripts\media_qc.py' '${PROJECTS_ROOT}\film\exports\final.mp4' --expected-size 1920x1080 --expected-fps 24 --require-audio --decode --count-frames --out '${PROJECTS_ROOT}\film\qa\final-media.json'
```

可选 `--audio-stats` 测量响度，不改变文件。无声片去掉 `--require-audio`。报告成功只表示所请求的技术检查通过；不代表没有口型、叙事或审美问题。

**逐镜/接点**：播放实际运动，不只看抽帧。重点检查身份/服装、手指和持物、脚底/重心、遮挡顺序、背景几何、文字、小结构、脸修边界、闪烁/鬼影、镜头速度与接缝。高速/接触镜头可逐帧回看；长镜头查每段接点前后完整动作及声音。

**整片**：按正常速度从头到尾观看和听完，检查观众能否理解、节奏、声音层级、首尾是否被截、字幕读速、事实和品牌准确；用实际目标屏幕/横竖比例检查裁切和界面遮挡。对白检查说话者/唇形，MV 检查乐句、拍点和歌词；抽帧不能替代此轮。

`assets/acceptance-checklist.md` 记录检查者、版本、缺陷、修复及未解决项。已发现关键缺陷应处理；检查工具无法播放/听音时如实报告验证缺口，不把机器探测写成人工观看通过。

## 返工决策

需要跟踪、动态遮罩、底板、准确屏幕/Logo替换、CG融合或动态图形时，执行[合成与镜头修复](compositing-and-repair.md)，不能把逐帧独立重画或静态羽化贴补当作稳定时序修复。镜间风格一致与层间融合均需正常速度观看。

| 问题 | 优先处理 |
|---|---|
| 情节/节奏不成立 | 改剪辑和必要覆盖，非全片锐化/升分辨率 |
| 身份或服饰漂移 | 统一有效参考、缩短镜头、局部返工；多人参考别混绑 |
| 相机/接触不准确 | 白模预演、简化动作/镜头、确定性 CG，而非叠更多形容词 |
| 接点跳变 | 修切点/声音桥，连续镜头重做必要相邻段；不要强行插值融脸 |
| 字幕/Logo/数字错误 | 后期准确叠层；动态遮挡需要合成检查 |
| 局部闪烁/变形 | 评估编辑/短段重生；脸修或二采只做对照试验 |
| 静音/重叠声音 | 回到独立主声音与时间线，不能以有 audio stream 判有有效声音 |
| 只有输出尺寸提升 | 标明交付放大；检查真实细节，不称无损/原生高分生成 |

## 交付清单

按请求提供最终视频、封面、字幕/无字版、必要音轨、可编辑工程及引用媒体；不是每次强制交付所有项。说明真实生成/交付规格、使用的关键流程、已解决及仍存限制。发布、账号上传和外部发送须有相应授权，制作完成不自动等于发布。

交付后按 [项目与收尾](project-operations.md) 完成缓存处理，保留足够复现和返工的记录；若还有返工计划，说明保留哪组缓存及用途。
