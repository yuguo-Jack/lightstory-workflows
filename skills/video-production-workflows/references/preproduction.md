# 前期、分镜与连续性

## 把主观输入变成可执行依据

保留用户剧本原意、审美样例与明确排除项，区分必须准确的内容与允许生成发挥的空间。可补写台词、镜头和动作，但不暗改关键剧情、产品事实或用户的风格选择。只有任务需要的知识/品牌事实才做对应检索。

新项目用 `assets/production-brief.md`。记录目标渠道、横竖屏、时长范围、交付尺寸/FPS、对白/旁白、字幕、音乐、可编辑工程及上传范围。未指定可建议 SDR、恒定 24/25/30fps；选择后全片统一，不为了流畅强制变成 60fps。分清生成尺寸、精修尺寸和交付尺寸。

将参考登记为：角色身份、服装/道具、场景结构、表面材质/光色、表演/动作、相机、声音。每张/段参考标明“控制什么、不要带入什么”。风格图不能悄悄重置人物，白模不能替代外观参考，视频中的音乐也不自动成为主音轨。

## 从剧本到镜头

每场先写“发生了什么变化/观众得到什么信息”，再决定镜头。按类型选择开场、建立环境、动作、反应、信息特写和结束；并非每场都要集齐。解说片先读旁白建立节奏，MV 先确定音乐窗口和段落，产品片先锁定商品与卖点，剧情片按表演/转折安排覆盖。

镜头记录至少包含：

- 唯一镜号、场景、叙事作用、人物/服装/道具版本。
- 景别、机位/视线、构图、光源方向；主要动作的起点、过程、终点。
- 一项可读的主要相机动作；运动方向、速度变化、开始/停止时刻和结束构图。
- 计划剪辑时长、生成时长、头尾余量、声音与对白；前后镜头如何衔接。
- 对应参考、H3 模式、难点及验收点，成功素材的实际路径/帧数。

`assets/shot-plan.json` 用整数帧、分数 FPS、源片入出点与实际时间线，区分计划帧和生成帧。项目较小时可以简化成表，但必须保留可重建剪辑的入出点和选片信息。

## 全片动态分镜（animatic）

分镜图按需求选工具：角色/道具外观先由Qwen基础参考编辑定稿；下一机位/景别候选可用Next-Scene，沿用布局/体积可用Qwen Fun边缘/深度控制；准确空间与运动则用Blender预演。操作与实测限制读`$comfyui-local-workflows`的`references/qwen-extensions.md`和`h3-controlnet.md`，不让分镜工具替代镜头表或整片审查。独立切镜与连续动作的结束帧分开制作；逐镜检查银幕方向、视线、身份/服装、空间关系和光线，再进入动态分镜。Next-Scene链式候选出现颗粒或地理漂移时回到干净锚点开分支，不能让低质量候选自动传到所有后镜。

正式批量生成前，将选定分镜图、临时对白/旁白或主音乐放到真实时间线上，按镜头计划设置停留、必要的简单运动、声音入点和转场，输出能从头播到尾的低成本预览。长项目可逐场完成再合并，简单单镜短片可以和试片合并，不机械多做一轮。

animatic回答“这部片在目标时长内是否讲清楚、动作/对白有没有时间完成、节奏与声音是否有效”。Blender白模预演回答某个镜头的空间/动作/相机如何实现，两者可以相互嵌入，但只做一个漂亮白模片段不代表已检查全片叙事。

对白主导时先做可用读稿或Ming临时声音，MV按已有音乐窗口；临时素材清楚标记，正式声音替换后复查实际停顿与时间。阶段锁定是记录当前有效选择，不意味着每步都要求用户重新批准。

animatic通过后再按镜头路线批量采样、替换占位素材并重新粗剪；不要让片长由一堆默认5秒素材随机相加。剧本或表演时长变化时更新受影响镜头的计划和依赖，确保后续声音、字幕和合成沿用最新时间线。

## 可剪辑的空间和动作

建立场景方位图及空间锚点：人站哪、看哪、走哪、物品在哪。相邻镜头保持银幕方向、视线、动作阶段和主要照明；越轴有目的时用中性机位/全景重新建立空间。不要把 180 度规则变成不能变机位的禁令。

动作镜头拆成准备、接触/峰值、反应/收势。复杂交互先验证接触和重心，再加速度、相机和特效。尽量让关键动作完整落在可用区间，保留适量剪辑余量；短片有限帧桶时优先保证动作可完成，不机械给每头尾固定一秒。

对白注意说话者、反应、口型可见程度和视线。旁白/B-roll 可不展示正面说话。需要准确唇形的近景要单独试，不能以语音转写正确当成口型通过。

## 风格及人物连续性

用 `assets/style-and-continuity.md` 记录：造型比例、材质、主辅色、对比/黑位、光线方向与软硬、摄影机高度/焦段倾向、运动方式、表演幅度、剪辑节奏和声音空间。用户要混合风格时明确每种风格负责的层面，避免把多个冲突关键词堆在同一镜头。

选择清楚、不矛盾的角色正面/侧面/服装锚点及场景参考，先筛查多视角是否真是同一角色。需要时用 Qwen 编辑生成同一造型的镜头构图，但生成的辅助视图也要验收；更多参考不必然更稳。

先试最能暴露问题的代表镜头：身份特写、风格全景、复杂交互或两段接点。通过后复用已选风格/角色版本，修改单变量返工。不要把全部预算花在无关的漂亮开场，直到后面才发现主要角色无法稳定表现。

## 按类型裁剪

| 类型 | 额外重点 |
|---|---|
| 剧情/短剧 | 情绪与行为变化、对话反打、角色连续性、声音空间 |
| 治愈/风格动画 | 形状语言、材质、运动节奏、表演与声音一致，不自动锁 Pixar |
| MV | 已有音乐为主时钟；段落、拍点、表演和文字包装按需，不强制写歌词 |
| 广告/产品 | 外观准确、卖点可证、包装 Logo/文字后期保真、真实 CTA |
| 科普/纪录 | 论述结构、出处/事实、画面对应信息；生成画面不冒充现场证据 |
| 预告/概念片 | 氛围、层次与悬念；不机械把完整剧情压缩成流水账 |
| 长镜头/追拍 | 路径和动作阶段、遮挡、起终构图、接点误差，优先做少量段落试验 |
