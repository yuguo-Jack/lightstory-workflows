# H3 类型技能的本机执行适配

适用于本机安装的 MiniMax 官方技能。上游八个类型流程为 MiniMax Hub 编写；本机保留其创作方法，将运行载体替换成已部署工具。**读取本文后再执行上游正文；本文规定当前本机路线，上游 Hub 工具名不是本机会话中的真实工具。** 用户明确选择优先于默认审美和重复确认卡片。

## 按内容选择一个主流程

| 技能调用名 | 适用 | 本机注意 |
|---|---|---|
| `$3d-animation-short-generator` | 叙事型风格 3D 动画 | 角色/场景卡、动作分镜、连续性检查有价值；Pixar/Q版仅为其默认，可被用户样例替换 |
| `$brand-promo-video-generator` | 品牌/应用/产品推广 | 用真实素材/事实；准确 UI、商标、文案优先在后期叠加 |
| `$minimalist-product-ad-generator` | 极简商品广告 | 造型锚点、干净布景、节奏包装；英文文案不是本机强制语言 |
| `$music-video-subtitle-generator` | MV、歌词视觉、音乐情绪片 | 保留用户歌曲作为主轨；无歌词/不需贴字时不强制编歌词或字幕 |
| `$paper-collage-explainer-generator` | 半色调纸拼贴科普/观点 | 视觉隐喻、纸张动作与拟音；不自动加旁白、字幕或 BGM |
| `$papercraft-stop-motion-explainer` | 纸雕立体书/微缩定格科普 | 信息准确与纸材质/定格运动；分镜适配本次内容 |
| `$handdrawn-live-video-generator` | 发光手绘与实拍空间融合 | 接触位置、变形、延迟追拍；15 秒/16:9 是配方默认而非所有项目硬上限 |
| `$co-op-game-intro-generator` | 双角色游戏片头/菜单动画 | 视频片头，不是可玩游戏；准确名字/菜单文字可用后期排版 |

角色写实短剧、纪录、动作、宏大场景等不匹配八类时，由总入口直接规划并调用 H3 提示词技能，不硬套无关类型。可借另一技能的局部方法，但不加载八套冲突默认一起运行。

当前 MV 的安装目录为 `${SKILLS_ROOT}/mv-subtitle-skill-confirmed`，其调用名仍为 `music-video-subtitle-generator`；保留旧目录避免破坏已有引用。其余目录与调用名一致。

## Hub 到本机的映射

| 上游表达 | 本机对应 |
|---|---|
| Canvas 的 brief / character cards / storyboard nodes | 当前项目的 Markdown、JSON、参考图、预览页；记录版本和实际文件链接 |
| `hub_generate_image` / 图像代理 | `$comfyui-local-workflows` → Qwen 图像；用户指定别的工具时再选择 |
| `hub_generate_video` / 视频代理 | `$comfyui-local-workflows`执行本地普通H3、Turbo或Flex等对应功能；总流程交出镜头目标和输入职责，执行技能负责配套、实际绑定、运行和单项审查 |
| Hub 参考槽/element cards | 命名素材 + 实际图片/视频/音频输入 + 提示词一致的引用标签 |
| `hub_synthesize_speech` | 由ComfyUI技能执行本地Ming TTS；并非当前存在同名工具 |
| `hub_generate_music` | 已有音乐直接复用；需要生成时由ComfyUI技能执行Music 3，不当精准环境拟音 |
| `hub_video_edit` / 最终合成 | CapCut 插件云路线、用户指定桌面路线，或明确范围内 FFmpeg 合成 |
| 选择卡 / 每步确认 | 已有用户选择直接沿用；缺关键信息才询问，普通本地工作继续。付费确认遵守服务要求 |
| H3 / Seedance / Kling 等模型选项 | 现有本地 H3 优先；别的模型不是已部署备选，不自动购买或安装 |

上游Hub专属frontmatter可从固定源码查阅，本地组装只保留支持的名称、描述和来源元数据，不把不存在的Hub工具作为执行白名单。上游中文`SKILL.cn.md`和辅助指南保留，本地入口是已适配的`SKILL.md`。

## 提示词更新如何应用

`$h3-prompt-writing` 是可移植的格式指南：基础模式三个段落，Ref2VA 六个段落。已合入的建议强调时间匹配、引用标签、具体描述、首尾帧路径。指南的4–15秒建议用于单次提示词示例；本机可用范围和帧桶由Comfy执行技能按当前节点确认，长片由分镜/延续/剪辑构成，不能把它当作成片只能15秒。

英文结构保留，台词/歌词/可见文本保留用户语言。结构化提示词是内容，不自动等于可直接POST的参数对象；先按[H3镜头制作](h3-production.md)组织意图，再由Comfy执行技能映射到实际接口。

## 运行与确认原则

用户要求完成影片时，文本分镜/提示词只是阶段成果；继续生成、剪辑、导出和检查。只要求分析/提示词时在相应范围结束，不启动重推理。授权、素材、风格或服务限制阻止下一步时解释实际原因；不能用上游每步“必须确认卡”人为制造八轮暂停。

如果未来上游改变创作规则，先比较源文件和本机改动，合入有价值变更并保留此适配，不用未经适配的 Hub 新版本直接覆盖本机执行入口。版本证据见 [sources.md](sources.md)。
