# 角色、服饰、绑定与动画

## 分开处理几何、皮肤和动作

角色“能打开”“能绑定”“能正确变形”“能在游戏交互”是四个不同阶段。先确认真实高度、方向、脚底、身体/衣服/道具组织、对称性、嘴眼和手指。长裙、斗篷、头发是独立的制作对象，不是给整体网格套骨架就结束。

绑定/动作方案明确后实际读取ComfyUI的[SkinTokens用法与边界](../../comfyui-local-workflows/references/skintokens.md)，或由`blender-core`路由到绑定/动画/真人动作技能。模型参数、CLI、格式和排错留执行层；新类别先用代表资产检查，不将已有少量角色验证外推全部动物/额外肢体。以下UE专有系统用于UE路线；Web由对应动画/物理执行分支实现同样的行为与验收目标。

近景角色优先修脸部体积、眼球/眼睑、唇口、发际与材质，必要时独立制作头部再接颈部、统一 UV/材质和蒙皮。高面数全身模型不保证近景脸好看；替换头部也不自动得到可用表情拓扑。

## 默认绑定路线

| 条件 | 路线 | 需检查 |
|---|---|---|
| 标准人形，接受免费云服务 | Mixamo 自动绑骨，或给已有角色下载其合法动作 | T/A姿势、四肢分离、比例、衣物影响、手部和动作可用性 |
| 需要本地控制骨架/精细返工 | Rigify metarig → 摆关节 → 生成控制骨架 → 权重 → 变形检查 → 游戏骨架/烘焙 | `--fit` 仅缩放/居中，不能当作自动关节识别 |
| 批量或非标准软体、动物、额外肢体；已有骨架需重算权重 | 可选已部署ComfyUI/SkinTokens，再进Blender审查 | 自动骨架/蒙皮不是控制器或动作；AI不能修复缺失/粘连几何；命名适配不等于骨架兼容 |
| 机械、坦克、车辆、铰链 | Blender刚性分件、父子关系/约束与程序运动，后续引擎适配 | 避免软蒙皮弯曲装甲；检查运动范围、轴、碰撞和履带/轮子关系 |

Mixamo 登录使用已授权的 Playwright 持久浏览器配置，按现有浏览器技能操作；不读取/导出登录凭据。模型上传仅限本任务指定素材，下载回项目收纳。免费服务不是本地离线工具，也不代表它能处理所有角色。

## 动作与重定向

动作来源可以是 Mixamo 预制片段、用户已有合法动作、Blender 关键帧或适合项目的 Epic 示例。先列所需行为，再选动作；不把 H3 视频当成骨骼动作，也不承诺从任意视频自动得到高质量 mocap。

需要复现真人表演且满足上游许可时，可经`blender-core`调用本机`blender-motion-capture`。它负责Motion2MixamoRig的身体/手指提取、一次提取多角色复用与Blender交接；具体操作、输入条件、材质保留和排错留在执行Skill，本总流程只决定采用与否。当前依赖有非商业研究限制；商业成品未另获授权时选Mixamo合法动作或自制动画。

批量复用先用代表性角色验动作、骨架和接触，再扩展。技术映射成功不代表不同身材、厚装甲或长武器都不穿模；根据握点、脚底、碰撞与运动空间做Blender/UE接触修正。动作素材、绑定结果和引擎运行端仍分开验收。

进入 UE 后匹配源/目标骨架的参考姿势、根、骨盆和肢体链，按 IK Retargeter 做映射。检查身高比例、足底、手腕、肩和根轨迹；骨架名字相似不保证相容。Root Motion 与原地动作根据控制方案选择，避免 CharacterMovement 与动画根位移互相叠加。

动画蓝图/状态机/Blend Space 接入速度、方向、空中/落地等实际状态；按项目需要处理起停、转身、加速、跳跃、下蹲和动作打断。复杂 motion matching 是可选升级，不能替代基本控制和动作过渡。

## 接触、服饰和物理

- 走路：测平地、坡、台阶、转身和起停；用脚 IK/Control Rig 按场景修正，检查锁脚和滑步，不只看静态骨架。
- 拿取：先定义物体把手/握点、手指姿态、持物 socket 和可交互范围，再匹配动画。通过明确事件切换世界物体、附着和物理状态，避免手里与地上同时各有一个。
- 放下/投掷：处理释放帧、碰撞恢复、初速度和可再次拾取。附着时不同时让同一个物体受无约束物理拉扯。
- 长衣与头发：先有合适的几何、权重/辅助骨，再决定是否需要 Chaos Cloth 或其他运行时模拟；配置身体碰撞代理、固定区、活动范围和 LOD。摆动是效果，穿模、爆炸和持续抖动是缺陷。
- 刚体/布料：Blender 模拟用于制作/烘焙的动画不会自动变成 UE 中可交互的实时物理，必须接入 UE 对应系统。反之，简单衣摆可用骨骼动画达到更稳定的结果。

## 面部与最终检查

眼口要有适合变形的拓扑、独立结构及需要的骨骼/形态键。Blender 技能创建 ARKit 52 名字的空槽不等于52个完成表情；实际制作眨眼、张口、关键情绪并检查组合形变。配音模型也不自动输出已匹配的嘴形动画。

检查双肩抬起、肘膝大角度弯曲、深蹲、头颈转动、手指、衣摆和代表性动作。导出后在所选运行端复查；UE检查实际骨骼网格、动画、Physics Asset与打包版本，Web检查实际骨骼/混合、碰撞、加载与正式构建。动画曲线、约束、形态键和材质在不同格式下各有支持边界。
