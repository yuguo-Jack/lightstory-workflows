# Qwen-Image 2.1：生图、编辑与建模参考



## 配套与基本操作



基础11份画布使用`qwen_image_2.1_int8_convrot`主权重、`qwen3vl_8b_int8_convrot`编码器和`qwen_image_2.1_vae_bf16`。VAE的BF16不代表主权重是BF16；旧BF16主权重已不保留。默认40步、CFG1、Euler/simple，没有默认图像风格LoRA；另有6份结构控制/分镜/可选人物通用画布，配方可能不同；读[扩展用法与限制](qwen-extensions.md)。额外叠加仍需核对Qwen-Image 2.1兼容和实际安装。



1. 在对应画布替换本次图片、提示词和种子；多参考明确每张职责，待编辑原图放第一位。

2. 文生图设置宽高；编辑优先使用编码节点给出的latent尺寸。参考编辑关闭KV缓存是Windows缓存复制问题的规避措施，会重复编码，不能当身份或像素锁定机制。

3. 生成与审查按[运行参考](runtime.md)。输出为原生`output/Qwen-Image 2.1`前缀下的PNG，以history路径和真实尺寸为准；透明图检查Alpha。



原生编辑使用图像条件＋参考latent，不是传统img2img的输入图加噪起点；当前`denoise=1`不能只凭其他模型经验随意降低。`TextEncodeQwenImage21.resolution`正值控制约该值平方的参考像素量，保持比例并按32对齐；0也会将宽高取整到32倍数。编辑latent按第一张有效参考的处理后尺寸创建，精确交付尺寸需另外明确缩放/裁切策略。



## 功能选择与边界



| 功能 | 输入与处理 |

|---|---|

| 文生图 | 自然语言描述主体、构图、材质和文字内容 |

| 单图编辑 | 图1为待编辑图，说明要保留和改变的内容 |

| 双图/五参考 | 分别定义身份、衣服、配饰、背景或风格职责；数量不保证一致性 |

| 蒙版局部编辑04 | 原图＋同尺寸黑白蒙版；白改黑保，扩展8px、羽化，生成后合成回预处理原图 |

| 透明背景05 / 抠图06 | 检查真实Alpha，放大发丝、镂空和半透明边缘 |



04的严格保护发生在**预处理后**的原图坐标中；若已缩放，不等于上传源文件逐像素不变，羽化带本来会混合。修小部件时蒙版应包含必要接缝上下文，不沿错误轮廓紧切。相同种子和多参考也不保证小单位、文字或几何边界精确还原。



## 给Pixal3D准备参考图



用08先得到纯背景、均匀光照的完整正面，手臂与身体、双腿分离；不要用景深、烟雾遮住结构。09背面/左右侧面均以同一正面为身份依据。



入模前比较头身比例、姿势、脚距、服饰扣件、轮廓与配饰；严格侧面应约90°，三分之二视图不能当侧面。先比较单正面与正背双图，不一致的侧面重做或不用；独立生成的视图不保证属于严格同一个三维物体。
