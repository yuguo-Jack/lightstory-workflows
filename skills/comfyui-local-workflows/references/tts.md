# Ming-3.0-TTS tiny：配音与多角色



当前配套为`ming-3.0-tts-tiny_int8_convrot`＋`ming-3.0_audio_vae`，默认flow_steps10、CFG2；不使用Music的DAV或H3音频VAE，也没有默认TTS LoRA。



适合文字旁白、对白、指定表演与多角色分段；仅需配音时本技能独立完成。先拿正文、语言/发音要求和音色目标；用户已有音色参考再选克隆，不能把参考嵌入当逐样本复制。输出是声音素材，不是录音转写、翻译、歌唱模型或口型动画；是否加入影片及如何剪辑由本次任务或上层决定。



## 选任务并填写生效字段



| 画布 | 当前任务与输入 |
|---|---|
| 01 内置音色 | `task=built-in voice`，`task.voice`选音色，输入正文 |
| 02 文字设计音色 | `task=voice design`，`task.description`描述年龄感、音高、发声与语气 |
| 03 参考音色克隆 | `task=speak`，`MingReferenceVoice → voice`接参考音频/转写 |
| 04 情绪与表演 | `task=emotion`，参考voice＋`task.emotion`；其他控制按对应任务模式选 |
| 05 多角色长文本 | `MingScript`按说话人组织正文，选内置音色或接对应`voice_1`等参考 |



任务模式决定有效字段，不能把情绪/速度/方言等描述写到任意位置就视为已控制。03/04模板须上传自己的参考，不能只留下空LoadAudio。参考建议单人、无背景音乐/混响的3–10秒音频；当前链路截前8秒，遇前导静音就改起点并同步转写。转写可留空，此时仅用说话人嵌入；准确转写可启用声学续接。



## 长文本与输出



```text

1 (voice=灵小柔): 欢迎来到今天的故事。

[pause 0.5]

2 (voice=灵小锋): 我们出发吧。

```



固定每个说话人的音色/参考。普通MingTTS默认max_fragment_length50并启用continuity；MingScript按行及原生分片处理，行间gap为0.25秒，显式pause另算。检查人名、数字、英文、多音字及分段语气，不保证长文完全无拼接感。



普通MingTTS输出latent后接音频VAE解码；MingScript自身输出已解码AUDIO和timeline，不能再当latent重复解码。默认成品为`output/Ming-3.0-TTS`下FLAC，需要WAV用音频工具转换。声音不包含角色口型/Blendshape驱动。



五主画布及七扩展场景已有运行记录；12项辅助转写与正文基本对应，但转写不能代替音色、情绪和相似度试听。辅助Whisper缓存已清理，不是正式画布依赖；新任务需要ASR才另行准备。详细请求和试听见[实测页](../../../docs/evidence/historical-summary.json)。
